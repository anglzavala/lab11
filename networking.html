Networking essentials

What makes a network work?

Devices use shared rules called protocols to exchange data. Switches connect devices locally, routers connect networks, and IP addresses help data find its destination.

  • LAN: a network over a local area
  • WAN: a network spanning long distances
  • Packets: small units of transmitted data

What is happening?

The source creates data and divides it into packets. A switch forwards local traffic; a router forwards traffic toward other networks.

Learn the layers

Interactive TCP/IP Model

Choose a layer to explore its responsibilities, common protocols, and a practical example.

Example: visiting a website

The Application layer prepares an HTTPS request. The Transport layer uses TCP to manage delivery. The Internet layer adds IP addressing and routes packets. The Network Access layer sends the data over Wi-Fi or Ethernet. The server's layers process the response in reverse.
